Внешние подключения и запуск

Supabase Database, Auth, Storage, Realtime и Cron подключены к svxgjisrkagmqjamnexp. Edge Function kapani-login развёрнута и проверена реальными тестовыми сеансами.

Для почтового запуска нужны SMTP, разрешённые адреса возврата Auth, подтверждение доставки писем регистрации и восстановления. CAPTCHA пока не подключена; не включайте её в Auth до настройки соответствующего интерфейса.

Для фоновой карты нужен разрешённый провайдер тайлов и его атрибуция. Проверка OpenStreetMap в облачном браузере показала блокировку, поэтому mapTiles=null. Дорожный маршрутизатор для такси и доставки ещё не интегрирован; формулы по прямой и фиктивной цены нет.

Web Push не реализован и VAPID-ключи не настроены. Настоящий мэр не назначен — нужен проверенный UUID реального зарегистрированного пользователя. Четыре технических аккаунта должны быть заблокированы перед публичным запуском с отзывом сеансов, без удаления истории. Публикация на GitHub Pages пока не выполнена.
